# Neon-Duell

Ein Zwei-Spieler-Spiel für eine Tastatur, direkt im Browser.

**Jetzt spielen:** https://brotschneider.github.io/neon-duell/

## Regeln

Beide Spieler ziehen eine Lichtspur hinter sich her. Wer gegen eine Wand oder eine Spur fährt (auch die eigene), verliert die Runde. Fahren beide gleichzeitig irgendwo rein, gibt es keinen Punkt. Wer zuerst 5 Punkte hat, gewinnt. Je länger eine Runde dauert, desto schneller wird es.

## Steuerung

|            | Spieler 1                      | Spieler 2                      |
|------------|--------------------------------|--------------------------------|
| Lenken     | `W` `A` `S` `D`                | Pfeiltasten                    |
| Turbo      | Taste in Fahrtrichtung halten  | Taste in Fahrtrichtung halten  |

`Leertaste` Start · `P` / `Esc` Pause · `M` Ton an/aus

Turbo verbraucht Energie (Leiste oben) und lädt sich von selbst wieder auf.
